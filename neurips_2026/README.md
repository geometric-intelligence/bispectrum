# NeurIPS 2026 submission (archival copy)

Verbatim LaTeX sources of the NeurIPS 2026 submission "bispectrum: Selective G-Bispectra Made Practical" (submission 10902), plus the OpenReview reviews and rebuttal in `reviews.md`. Sole deviation from the submitted zip: the invalid `[anonymized]` option on `\usepackage{neurips_2026}` was removed so the sources compile (anonymous is the sty default).

Build: `tectonic bispectrum.tex`
